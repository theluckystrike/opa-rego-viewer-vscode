# Changelog

## 0.1.0

- First release: `*.rego` Open Policy Agent, Conftest and Gatekeeper policies in a read-only offline inspector, parsed locally with plain JavaScript and zero OPA binary, shell or cloud calls.
- Package, import, rule and function explorer (`allow`, `deny`, `violation`, `default`), `input.*`/`data.*` reference table and static policy findings (`default allow := true` fail-open hazard, missing `import rego.v1`, unused helper rules, unbounded wildcard loops, hardcoded tokens).
- Zovo Pro tools with 1 free try each: Markdown Rego fail-open and best-practice audit, two-file `.rego` Markdown diff, and Markdown plus CSV rule and input-path catalog export. Get Zovo Pro first shows what Pro includes and the tries left, in an editor tab.
